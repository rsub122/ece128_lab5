# ECE128 Lab 5

The purpose of this lab is to design and simulate common sequential logic circuits in Verilog. The designs include an SR latch, SR flip-flop, positive-edge D flip-flops with synchronous and asynchronous reset, a T flip-flop, a 3-bit counter using T flip-flops, and a 25 MHz clock divider.

Each required design has its own testbench so the waveform can be simulated and analyzed separately.

## Required Design and Testbench Files

- SR_Latch.v / SR_Latch_TB.v
- SR_FlipFlop.v / SR_FlipFlop_TB.v
- DFlipFlop_sync.v / DFlipFlop_sync_TB.v
- DFlipFlop_async.v / DFlipFlop_async_TB.v
- TFlipFlopCounter.v / TFlipFlopCounter_TB.v
- Counter3_TFlipFlop.v / Counter3_TB.v
- clockdivider.v / clockdivider_TB.v

The D and T flip-flop designs use the active-low reset rstn convention used in the ECE 128 lecture.

## FPGA Demonstration Files

- Lab5_FPGA_Top.v
- SlowClock.v
- Basys3_Lab5.xdc

Lab5_FPGA_Top instantiates the Lab 5 designs and allows the circuit being demonstrated to be selected with SW4-SW2. SW1 and SW0 are the circuit inputs. BTNC is reset. The top module internally converts BTNC to active-low rstn.

### FPGA Mode Select

| SW4 SW3 SW2 | Design | Controls | Output |
|---|---|---|---|
| 000 | SR latch | SW0=S, SW1=R | LED0=Q, LED1=Qbar |
| 001 | SR flip-flop | SW0=S, SW1=R | LED0=Q, LED1=Qbar |
| 010 | D FF synchronous reset | SW0=D, BTNC=reset | LED0=Q |
| 011 | D FF asynchronous reset | SW0=D, BTNC=reset | LED0=Q |
| 100 | T FF | SW0=T, BTNC=reset | LED0=Q |
| 101 | 3-bit counter | SW0=EN, BTNC=reset | LED2-LED0=Q2-Q0 |
| 110 | 25 MHz divider | none | LED0=25 MHz output, JA1=25 MHz output |
| 111 | slow demonstration clock | none | LED0=slow clock |

The SR flip-flop, D flip-flops, T flip-flop, and counter use a slow demonstration clock generated by SlowClock.v so state changes can be seen on LEDs. This helper does not replace the required 25 MHz clock-divider design.

## Vivado Simulation Instructions

1. Create a new Vivado RTL project for the Basys 3 board.
2. Add the required design file under Design Sources.
3. Add its matching testbench under Simulation Sources.
4. Set the testbench as the simulation top.
5. Run Behavioral Simulation.
6. Verify the waveform against the truth table or expected counter sequence.

## FPGA Implementation Instructions

1. In the same Vivado project, add all required design files plus Lab5_FPGA_Top.v and SlowClock.v as Design Sources.
2. Add Basys3_Lab5.xdc under Constraints.
3. Set Lab5_FPGA_Top as the top module.
4. Run Synthesis.
5. Run Implementation.
6. Run Generate Bitstream.
7. Open Hardware Manager, connect to the Basys 3, and program the device.
8. Use SW4-SW2 to select the design and use SW1/SW0 and BTNC as listed above.
9. For the 25 MHz divider, the output is too fast to see blinking on an LED. The same 25 MHz signal is routed to JA1 for measurement if lab equipment is available.

The Basys 3 pin mappings in Basys3_Lab5.xdc use the official Digilent Basys 3 master XDC assignments for the 100 MHz clock, switches, LEDs, center push button, and JA1.
